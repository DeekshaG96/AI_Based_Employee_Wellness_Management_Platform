Built as a full-stack project

Thoughtful analysis, from input to insight.

The dashboard sends account-authenticated requests to a Python API. The service validates text, runs NLP analysis, and stores each account's history in PostgreSQL.

Interactive dashboardStreamlit
Application APIFastAPI + Pydantic
Text processingspaCy + NLTK + VADER
Data and emotion analysisPostgreSQL + Transformers
ⓘ

Use results with care

MoodMentor is an educational self-reflection prototype, not a clinical assessment or emergency service. Text models can misunderstand context, culture, sarcasm, and mixed feelings. Do not use these estimates for employee evaluation or other high-impact decisions. Free hosted services may sleep between visits and the hosted database is temporary.
