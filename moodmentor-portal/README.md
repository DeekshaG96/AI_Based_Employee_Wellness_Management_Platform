# MoodMentor | Workplace Wellness & Affective Intelligence Portal

Welcome to the **MoodMentor Interactive Web Portal**. This is an award-winning, responsive, animated wellness application designed for employees and workforce leadership.

---

### What's Inside:
1. **Real-Time Mood Analyzer**: Interactive text reflection analyzer with live VADER sentiment compound meter, fine-grained multi-label emotion telemetry (Joy, Gratitude, Pride, Stress, Fatigue, Frustration), and personalized CBT action steps.
2. **Animated Mascot ("Aura")**: An animated SVG companion whose facial expression, breathing rate, and glowing aura dynamically react to employee sentiment.
3. **SomaSanctuary Breathwork & Audio**: 
   - Stanford Protocol Box Breathing visual pacer (4s Inhale, 4s Hold, 4s Exhale, 4s Pause) with expanding glow.
   - Procedural Web Audio API sound generator with zero external network downloads (Gentle Rain, Ocean Tide, 432Hz Tibetan Singing Bowl, Binaural Zen Drone).
   - Interactive 5-4-3-2-1 Sensory Grounding checklist.
4. **Mood-Food & Nutritional Psychiatry Studio**: Targeted gut-brain axis meal protocols for stress reduction, cellular mitochondrial renewal, and cognitive vitality with dietary pattern toggles (Omnivore, Vegetarian, Vegan).
5. **ResilienceRadar Team Morale Simulator**: 14-day team sentiment trajectory canvas graph, Burnout Risk Index, and management interventions.
6. **Confidential Journal & History**: 100% private in-browser storage, with 1-click export to Markdown (`.md`), printable PDF report, and CSV.

---

### How to Run:
- **Direct Launch**: Simply double-click `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
- **Local Server (Optional)**:
  ```bash
  python -m http.server 3000
  ```
  Then open `http://localhost:3000` in your browser.
